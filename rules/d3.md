# Regras de Desenvolvimento: Visualização de Dados (D3.js)

> **Hoje o projeto não usa D3.** A corrente da etapa 4 é feita com React + Framer Motion (`ChainBlock`, `ChainLink`). Estas regras valem se um diagrama em D3 for adicionado no futuro.

## 1. Escopo e Responsabilidade
Este contexto aplica-se exclusivamente aos componentes responsáveis por desenhar gráficos vetoriais (SVG) e diagramas de rede, utilizando a biblioteca `d3.js`. O foco principal é renderizar a ligação criptográfica da cadeia de blocos (Blockchain) e o fluxo da rede *peer-to-peer*.

## 2. A Fronteira React vs. D3.js
Tanto o React quanto o D3.js são bibliotecas que manipulam o DOM. Para evitar conflitos e falhas de renderização, a seguinte regra de fronteira é inegociável:
* **React gerencia os Dados (State):** O React é o único responsável por armazenar o array de blocos, capturar as interações do usuário e calcular o estado atual da simulação.
* **D3.js gerencia apenas o Desenho (SVG):** O D3.js não deve armazenar estado global. Ele atua apenas como uma ferramenta de pintura que recebe os dados do React e os desenha na tela.

## 3. Padrão de Integração Obrigatório
A integração entre as duas ferramentas deve ocorrer estritamente através do uso de `Refs`:
1. O React renderiza um elemento contêiner vazio: `<svg ref={svgRef}></svg>`.
2. Um `useEffect` no componente React monitora as mudanças nos dados da Blockchain.
3. Quando os dados mudam, o `useEffect` aciona uma função pura do D3.js, passando o `svgRef.current` e os novos dados como parâmetros.
4. O D3.js limpa o SVG (se necessário) e aplica as transições orientadas a dados (Data-Driven) para atualizar os nós e os links na tela.

## 4. Foco Didático da Visualização
* **Quebra de Corrente:** A visualização deve destacar de forma óbvia (ex: mudança drástica de cor, quebra da linha de conexão) quando a imutabilidade for violada (quando o *hash* de um bloco anterior for alterado e não bater com a referência do bloco seguinte).
* **Transições:** Utilize o módulo de transição nativo do D3 (`d3.transition()`) para animar a entrada de um novo bloco na cadeia. O movimento ajuda o aluno a entender a ordem cronológica do registro.

## 5. Limpeza e Performance
* **Unmount:** Todo `useEffect` que inicializa uma simulação do D3.js (especialmente simulações de força, como `d3.forceSimulation`) deve retornar uma função de limpeza (*cleanup function*) para interromper a simulação ou remover os elementos do DOM quando o componente React for desmontado. Isso evita vazamento de memória e sobrecarga no navegador.
